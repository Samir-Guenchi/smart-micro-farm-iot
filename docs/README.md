## Notes on the visa applications

The two `.docx` files are kept as they were submitted, so they are not edited
here. Read them with these points in mind:

- **Name.** "SmartFarm Mini" (v2) and "GreenLoop Farm" (v4-2) are the same
  project; GreenLoop Farm is the current name, used everywhere else in this
  repository.
- **Contact email.** The two applications use two different personal emails.
  The public contact is the one in the main [README](../README.md#founder).
- **Repository link.** The GreenLoop application links
  `github.com/hinitbth-droid/smart-micro-farm-iot`, the original repository.
  Development now happens in `github.com/Samir-Guenchi/smart-micro-farm-iot`,
  which was copied from it with full history.
- **Arabic documentation.** The SmartFarm application says the project has
  documentation in Arabic and English. That is now true: see
  [README.ar.md](../README.ar.md) (and [README.fr.md](../README.fr.md)).
- **Privacy.** Both applications contain personal details (emails,
  nationality, background). The repository is private today. Before it is
  made public, move them to private storage and keep only this index.
